## What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page and consists of elements that tell the browser how to display content.

## Basic Structure

Every HTML document follows a basic structure:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>
    <!-- Your content goes here -->
</body>
</html>
```

3. Try modifying the code to see what happens

## Opening HTML Files

Simply double-click any `.html` file to open it in your default web browser, or right-click and select "Open with" to choose a specific browser.
