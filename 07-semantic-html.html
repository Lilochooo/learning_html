Understanding Semantic HTML

January 15, 2024 by John Doe

What is Semantic HTML?

Semantic HTML uses elements that clearly describe their meaning in a human- and machine-readable way. Instead of using generic <div> elements for everything, semantic elements tell you what type of content they contain.

Why Use Semantic HTML?

  • Accessibility: Screen readers can better understand page structure
  • SEO: Search engines understand your content better
  • Maintainability: Code is easier to read and maintain
  • Future-proof: Better support for new technologies

Common Semantic Elements

<header>
Represents introductory content or navigational aids
<nav>
Contains navigation links
<main>
The main content of the document (only one per page)
<article>
Independent, self-contained content (blog post, news article)
<section>
Thematic grouping of content
<aside>
Sidebar content, tangentially related to main content
<footer>
Footer for document or section
<figure> and <figcaption>
Self-contained content with optional caption

HTML5 vs HTML4

January 10, 2024

Key Differences

HTML5 introduced many semantic elements that weren't available in HTML4. This makes it easier to create well-structured, accessible web pages.

Before and After

Old way (HTML4):

<div id="header">
    <div id="nav">...</div>
</div>
<div id="main">...</div>
<div id="footer">...</div>

New way (HTML5):

<header>
    <nav>...</nav>
</header>
<main>...</main>
<footer>...</footer>
