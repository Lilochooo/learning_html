Image Attributes Explained

src (source)

The src attribute specifies the path to the image file. It can be:

  • Relative path: images/photo.jpg (file in same folder structure)
  • Absolute URL: https://example.com/image.jpg (full web address)

alt (alternative text)

The alt attribute is required for accessibility. It describes the image for:

  • Screen readers (for visually impaired users)
  • When the image fails to load
  • Search engines

width and height

These attributes set the display size. It's good practice to include them to prevent layout shifts.

Practice Exercise

Create a page with:

  1. At least 3 links to different websites
  2. One link that opens in a new tab
  3. An email link
  4. At least 2 images (you can use placeholder images or find free images online)
  5. One image that is also a clickable link
  6. Make sure all images have proper alt text

Tip: To use your own images, create an "images" folder in the same directory as your HTML file, and reference them like: <img src="images/your-photo.jpg" alt="Description">
