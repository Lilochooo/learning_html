Important Form Attributes

Form Attributes

  • action: Where to send form data (URL)
  • method: How to send data (GET or POST)
  • enctype: Encoding type (important for file uploads)

Input Attributes

  • type: The input type (text, email, password, etc.)
  • name: Name of the field (used when submitting)
  • id: Unique identifier (used with label's "for" attribute)
  • value: Default value
  • placeholder: Hint text shown in empty fields
  • required: Field must be filled before submitting
  • disabled: Field cannot be edited
  • readonly: Field can be seen but not edited
  • min/max: Minimum/maximum values (for numbers/dates)
  • pattern: Regular expression for validation
