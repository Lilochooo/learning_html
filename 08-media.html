Audio Attributes Explained

  • controls: Shows play/pause and volume controls
  • autoplay: Starts playing automatically (often blocked by browsers)
  • loop: Repeats the audio when it ends
  • muted: Starts with sound muted
  • preload: "auto", "metadata", or "none" - when to load the audio

Video Attributes Explained

  • controls: Shows video controls (play, pause, volume, etc.)
  • width/height: Sets video dimensions
  • poster: Image shown before video plays
  • autoplay: Starts playing automatically (often blocked)
  • loop: Repeats video when it ends
  • muted: Starts with sound muted
  • preload: When to load the video

Iframe Attributes

  • src: URL of the page to embed
  • width/height: Dimensions of the iframe
  • title: Accessible title for screen readers
  • sandbox: Security restrictions (important for untrusted content)
  • allowfullscreen: Allows fullscreen mode

Best Practices

  • Always provide fallback content for audio/video elements
  • Use multiple formats (MP4, WebM, OGG) for better browser support
  • Include width and height to prevent layout shifts
  • Use poster images for videos to show a preview
  • Consider file sizes - large media files slow down pages
  • Provide captions/subtitles for accessibility (use <track> element)
  • Be mindful of autoplay - many browsers block it
  • Use iframes carefully - they can impact page performance

Practice Exercise

Create a media-rich page with:

  1. At least 2 images (with proper alt text)
  2. An audio player with controls
  3. A video player with controls and poster image
  4. An embedded YouTube video using iframe
  5. Make all media responsive (work on mobile devices)
  6. Add fallback text for audio/video elements
